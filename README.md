# go-directory-syncer

Directories data syncing on fly

---

## Build

go build -o "..../go-directory-syncer" go-directory-syncer.go

---

## Run

`go run ..../go-directory-syncer.go --source-directory="..../go-directory-syncer/test/source_directory" --destination-directory="..../go-directory-syncer/test/destination_directory";`

`"..../go-directory-syncer/go-directory-syncer" --source-directory="..../go-directory-syncer/test/source_directory" --destination-directory="..../go-directory-syncer/test/destination_directory";`
